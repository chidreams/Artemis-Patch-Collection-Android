## 🔧 How It Works
Android PS3 emulators like **ARMSX** support external patch files for memory modification.

This project converts Aldo’s original cheat database into a format that:

- Loads correctly on Android  
- Avoids RPCS3 YAML structures  
- Uses stable offsets  
- Displays game version (e.g., *BLUS31010 v1.03*)  
- Reduces confusion between game revisions  

All patches are manually validated for compatibility.

## 📥 Usage (Android / ARMSX)
1. Download the latest Android patch file from this repository.  
2. Place it inside your emulator’s patch directory.  
3. Launch your emulator and open the patch menu for your game.  
4. Enable the cheats you want to use.
