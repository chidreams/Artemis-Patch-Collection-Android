Artemis Patch Collection — Android Edition
A curated, mobile‑ready collection of Artemis PS3 patch files optimized for use with Artemis Patch Manager — Android. This repo serves as the official patch library for the Android ecosystem, providing clean, validated, and version‑sorted patches that work seamlessly across supported titles.

What This Repo Provides
Verified Artemis patch.yml and Imported_patch.yml files

Region‑sorted patch groups (BLES, BLUS, NPUB, NPEB, etc.)

Multi‑version patch sets with consistent formatting

Fixes for broken, outdated, or malformed patches

Mobile‑friendly structure for fast loading inside the Android manager

Purpose
To maintain a unified, reliable patch library for Android users. Whether you're testing cheats, porting patches, or validating multi‑version support, this repo keeps everything clean, organized, and compatible with the Artemis ecosystem.

Status
Actively maintained. New patches, fixes, and version updates added regularly.
